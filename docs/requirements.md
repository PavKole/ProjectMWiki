# Сбор требований

## ОС сервисов проекта
Ubuntu Server 22.04 LTS для всех узлов (кроме mon1 — Ubuntu 24.04 LTS).

## Необходимые библиотеки и фреймворки
- PHP 8.3+ и расширения: php-fpm, php-pgsql, php-mbstring, php-xml, php-intl, php-json, php-curl, php-apcu
- MediaWiki 1.42.1
- Nginx
- PostgreSQL 14
- NFS-клиент
- Prometheus, node_exporter, Grafana
- Zabbix server и agent
- Утилиты: pg_dump, tar, rsync

## Планируемая нагрузка
- До 50 одновременных пользователей
- Около 500 зарегистрированных
- Пиковые запросы: ~100 RPS
- Объём БД: до 5 ГБ
- Загруженные файлы: до 20 ГБ

## Специфика приложения
MediaWiki — вики-движок, использует БД для страниц и метаданных, ФС для загруженных файлов. Требует общего файлового хранилища между экземплярами.

## Интерфейс взаимодействия
HTTP/HTTPS через балансировщик Nginx.

## Вспомогательные сервисы
SSH, NTP, DNS (внутренние имена), PostgreSQL с репликацией, NFS, мониторинг, резервное копирование.
